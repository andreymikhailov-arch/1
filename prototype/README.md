# Прототип витрины IDODOM

Проверка концепции: 3D-конфигуратор столов (опора × плита × форма × размер × отделка, шпон с раскладкой и лаком), живая цена, витрина категорий, скульптуры с масштабом.

- Готовый файл: `dist/idodom-prototype.html` – открывается двойным кликом, работает без сервера, можно переслать.
- Исходники: `src/` (three.js без фреймворка), сборка `npm i && npm run build`.
- Плиты и рендеры нарезаны из страниц каталога (`npm run assets <папка>`), поэтому текстуры мыльные – в бою нужны сканы плит от производителя.
- Цены демо. Внизу слева переключатель режима цены: точная / от / по запросу – для обсуждения с клиентом.
- 3D-опоры построены по рендерам на глаз; в бою – модели по чертежам или исходники от поставщика.
